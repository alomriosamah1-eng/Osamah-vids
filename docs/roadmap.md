# خطة التنفيذ المرحلية — roadmap.md

| # | المرحلة | المخرج | الحالة |
|---|---|---|---|
| 0 | تهيئة المستودع + التوثيق + الأدوات | هيكل + docs + `tools:vendor` + تثبيت الحزم | ✅ كود جاهز ⚠️ يلزم `npm install` متكامل + إعادة `tools:vendor` (ffmpeg static) |

| 2 | شاشات الرئيسية / مشروع جديد / المشاريع | تجربة أمامية كاملة | ✅ كود جاهز ⚠️ غير متحقَّق بعد |

| 3 | محرر CapCut + مولّد أحداث حيّ وهمي | عرض لحظي بلا خلفية | 🔄 EditorScreen مكتوب — يلزم ربط + فحص |

| 5 | الأنابيب الحقيقية (opencode + edge-tts + Playwright + ffmpeg) | فيديو حقيقي من برومبت | ⏳ |
| 6 | التعديل بالمحرر عبر الوكيل | حلقة تعديل حيّة | ⏳ |
| 7 | إحصاءات + إعدادات + تغليف + اختبارات + توثيق نهائي | مثبّت + `TEST_REPORT.md` | ⏳ |

> **خطة المعرض (مواصفة):** تبويب «المعرض» في الـ Sidebar يعرض الفيديوهات الجاهزة (`status=ready`) بمبدّل شبكة/قائمة، وترتيب: الحجم / الاسم / الأحدث / الأقدم / آخر فتح (يتطلب حقل `lastOpened` وربما `sizeMb` في المستودع). مشغّل فيديو داخلي: تالٍ/سابق، أوضاع عرض (fit/cover/stretch)، رفع/خفض/كتم الصوت، تشغيل/إيقاف/استئناف، عارض جودة، سرعة 0.25–2×.

## المخاطر
| المخاطرة | التخفيف |
|---|---|
| مسار تمرير برومبت opencode | اختبار ميداني في م4 + دعم argv وstdin |
| مدة 60 دقيقة | تقسيم دفعات مشاهد + تسجيل متقطّع بالسياق نفسه |
| ثقل ffmpeg النظامي | توطين static build |
| خطوط RTL | تضمين الخطوط محليًا |
| تغيّر نسخ opencode | الاعتماد على CLI/NDJSON لا SDK داخليًا |
| تعلّق عمليات خلفية (bash timeout 120s) | `setsid nohup … > log &` ثم استطلاع؛ تجنّب `pkill -f` بمطابقة نصّ أداة الـ shell |
