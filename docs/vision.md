# الرؤية — Osamah vids ai

## المشكلة
إنتاج فيديو احترافي (وثائقي/تعليمي/إعلامي) يتطلّب كتابة سكربت، تصميم مشاهد، تعليق صوتي، موسيقى، ومونتاج — دورة طويلة ويدوية.

## الحل
تطبيق سطح مكتب يكتب فيه المستخدم برومبتًا واحدًا + خيارات (مدة، اتجاه، أسلوب، صوت، جودة)، فيتولّى **وكيل opencode** إنشاء السكربت والمشاهد (كبيانات JSON)، ثم تقوم المنظومة تلقائيًا بتوليد التعليق الصوتي، تسجيل الشاشة حيًّا (Playwright)، مزج الصوت (ffmpeg)، وتصدير MP4 — كل ذلك مع **محرر حيّ** يعرض الطبقات وهي تُنتَج لحظيًا وإمكانية إعطاء الوكيل تعليمات تعديل.

## المستخدم المستهدف
- صانع محتوى عربي يريد فيديو جاهزًا بسرعة.
- معلّم/إعلامي/مسوّق يحتاج مقاطع بأسلوب محدّد.
- محرّك متقدّم يريد التحكم في الطبقات والتعديل بالمحادثة.

## حالات الاستخدام الأساسية
1. **مشروع جديد**: برومبت + خيارات → توليد → محرر حيّ → تصدير.
2. **فتح مشروع**: استعراض سابق → محرر + إضافة تعليمات للوكيل → إعادة إنتاج.
3. **لوحة الرئيسية**: إحصاءات الاستخدام والإنتاج.
