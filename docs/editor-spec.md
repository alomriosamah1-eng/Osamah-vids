# مواصفة المحرر (CapCut-like) — editor-spec.md

## الهدف
واجهة مونتاج حيّة تُظهر **مسارات** الإنتاج وتُحدَّث لحظيًا عبر SSE، مع حقل تعليمات للوكيل.

## التخطيط
```
┌──────────────────────────────────────────── TopBar ────────────────────────────────────────────┐
│ [شعار + Osamah vids ai]                 [الحالة/التقدّم]        [تصدير] [الوضع الفاتح/الداكن]     │
├──────────┬───────────────────────────────────────────────────────────────┬─────────────────────┤
│ Sidebar  │                    Preview Monitor (9:16 / 16:9)               │  لوحة الوكيل          │
│ الرئيسية  │                                                                │  حقل التعليمات       │
│ جديد     │                                                                │  سجلّ الأحداث         │
│ المشاريع │                                                                │                     │
├──────────┴───────────────────────────────────────────────────────────────┴─────────────────────┤
│ Timeline: [ruler]                                                                              │
│  ▸ مشاهد   ║ [scene1][scene2][scene3][scene4]                                                  │
│  ▸ تعليق   ║ [ar01][nar02][nar03]                                                             │
│  ▸ موسيقى  ║ [======== music bed ========]                                                   │
│  ▸ ترجمات  ║ [sub1][sub2]...                                                                  │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

## نموذج الخط الزمني (Track/Clip)
```ts
type TrackKind = 'scenes' | 'narration' | 'music' | 'captions';
interface Clip { id; label; startMs; durMs; status: 'pending'|'generating'|'ready'|'error'; src?; thumb?; }
interface Track { id; kind: TrackKind; clips: Clip[]; muted?: boolean; }
interface Timeline { durationMs; rpm: number; tracks: Track[]; }
```

## حالات المقطع
`pending` (رمادي) → `generating` (نبض/تدرّج) → `ready` (مصغّرة + مدة) → `error` (أحمر).

## التفاعل
- نقر مقطع: معاينة المشهد/الاستماع للتعليق + تحديد تزامن.
- Playhead: تحريك + تشغيل/إيقاف؛ العرض يتبع اللقطة الزمنية.
- تغيير التكبير: `pxPerSecond`.
- التعليمات للوكيل: نصّ + إرسال → `POST /edit` → تظهر التعديلات عبر الأحداث.

## الإصدار v1
عرض حيّ وقراءة فقط للمقاطع + إعادة ترتيب أساسي؛ لا قصّ/تقطيع حرّ بعد.
