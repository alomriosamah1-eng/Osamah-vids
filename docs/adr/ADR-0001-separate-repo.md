# ADR-0001 — مستودع منفصل داخل program/

- **التاريخ**: 2026-10-10
- **الحالة**: مقبول

## السياق
يوجد مشروع `Osamah-vids` غنيّ بأربع طبقات (app/server/core/electron). مطلوب برنامج جديد باسم «Osamah vids ai» بنفس تقنية الإنتاج (تسجيل Playwright المستمر).

## القرار
إنشاء **مستودع منفصل** في `/home/osamah/program/Osamah-vids-ai`، مع إعادة استخدام *أنماط* الكود من المشروع القديم (نسخ/تكييف) لا الاستيراد منه.

## البدائل
- التوسّع داخل `Osamah-vids` مباشرة — يخلط نطاقين ويُعقّد التتبّع.
- فرع داخل المستودع — لا يعطي نظافة فصل.

## الأثر
استقلالية كاملة، توثيق نظيف، وحرية في اختيار المكدّس (React web + Electron) بدل React Native الحالي.
