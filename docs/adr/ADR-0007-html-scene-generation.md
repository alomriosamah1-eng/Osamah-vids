# ADR-0007 — مشاهد HTML/CSS/JS يولّدها الوكيل (يُعدِّل ADR-0002)

- **التاريخ**: 2026-10-11
- **الحالة**: مقبول (يُبطل جزئيًّا بند «لا كود خام من الوكيل» في ADR-0002)

## السياق
قرار ADR-0002 (عقد JSON + محرّك ثابت) منح أمانًا واتّساقًا وقابلية ربط بالمحرر، لكنه قيّد التصميم إلى أنواع طبقات محدودة، فخرجت المشاهد كـ«نصوص على خلفية» لا كتصميم موشن‑جرافيك احترافي. المطلوب الفعلي من المستخدم: تصميم الفيديو بأن يُنشئ الوكيل تصميمًا حقيقيًّا (تخطيط، مساحات، تدرجات، أشكال SVG، مخططات) بلغة HTML/CSS/JS.

## القرار
- **المسار الافتراضي**: لكل مشهد يولّد الوكيل **مستند HTML واحد قائم بذاته** يُحفظ في `projects/<id>/scenes/scene_NN.html`.
- **العقد الإلزامي**: `window.__ready` (bool يُضبط بعد تجهيز الـDOM) و`window.__seek(tMs, durMs)` المسؤولة الوحيدة عن الحركة كدالة خالصة للزمن.
- **الحتمية مفروضة تقنيًّا**: الشبكة محجوبة في الالتقاط، CSS animations/transitions مُجمَّدة، `requestAnimationFrame` مُحيَّد، لا موارد خارجية ولا عشوائية غير مزروعة.
- **لوحة تصميم ثابتة**: 1920×1080 (أفقي) / 1080×1920 (عمودي)، والخرج يُحجَّم إلى دقة المشروع عبر `ffmpeg scale` (lanczos).
- **يبقى مسار JSON متاحًا** (`render.sceneMode:"json"`) للمحرر والتحقق الصارم عبر zod — لكنه لم يعد الافتراضي.

## الأسباب
- تصميم احترافي حقيقي كما طلب المستخدم.
- حتمية مضمونة بالعقد + تجميد الحركة + الالتقاط بالـ`__seek` (بدل الاعتماد على CSS/زمن النظام).
- مرونة بصرية كاملة دون توسيع محرّك الطبقات باستمرار.

## الأثر
- محوّلات جديدة: `generateScenesHtml` (توليد + تحقق العقد) و`captureHtmlFrames` (setContent + seek + screenshot).
- `render.sceneMode` في الإعدادات، و`PipelineUnit` موحّدة في الأنبوب، وتحجيم في `encodeImageSequence`.
- زمن التقاط أعلى للتصاميم الثقيلة (تأثير زجاجي/تدرجات) — بند تحسين لاحق (التقاط بدقة الخرج، أو CUDA/برمجيّ أسرع).
- محرر الواجهة (JSON) يخدم وضع `json` حاليًا؛ معاينة/تحرير HTML بند لاحق.

## مراجع
ADR-0002، ADR-0004، النموذج الأصلي في `try/`، و`docs/scene-contract-html.md`.
