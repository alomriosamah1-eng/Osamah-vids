# ADR-0004 — تسجيل شاشة مستمر بسياق واحد (لا استخراج صور)

- **التاريخ**: 2026-10-10
- **الحالة**: مقبول

## السياق
استخراج 30 لقطة/ث أخّر الإنتاج (415–700ms/إطار) وأنتج وميضًا أبيض عند حدود المقاطع بسبب سياق تسجيل جديد لكل مشهد.

## القرار
تسجيل الفيلم كاملًا كتشغيل متّصل واحد في سياق صفحة واحد عبر Playwright `recordVideo`، مع ساعة افتراضية 30fps تُحرّك `__seek(f, t)`.

## الأثر
- لا وصلات/وميض؛ حركة سلسة.
- زمن التسجيل ≈ الزمن الحقيقي للفيلم.
- ffmpeg يتولّى CFR 30 والترميز النهائي.

## مراجع
`try/render/live_capture.mjs` (النموذج الأصلي).
