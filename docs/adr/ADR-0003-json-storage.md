# ADR-0003 — تخزين بملفات JSON (لا قاعدة بيانات الآن)

- **التاريخ**: 2026-10-10
- **الحالة**: مقبول

## السياق
Node 20.20.2 لا يدعم `node:sqlite` (يتطلّب ≥22). والتطبيق سطح مكتب أحادي المستخدم.

## القرار
تخزين كل مشروع في مجلد بخلف ملفات JSON + `events.ndjson`، خلف واجهة `ProjectRepository` في `packages/core`.

## البدائل
- better-sqlite3 الآن — تعقيد بلا حاجة في v1.
- رفع Node لـ 22 — خارج نطاق التحكّم.

## الأثر
سهولة النسخ/الاستعراض. عند الحاجة لإحصاءات ثقيلة يُضاف SQLite لاحقًا كمفهرس فقط دون تغيير الواجهة.
