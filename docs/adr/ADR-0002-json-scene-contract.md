# ADR-0002 — عقد مشهد JSON + محرّك، لا كود خام من الوكيل

- **التاريخ**: 2026-10-10
- **الحالة**: مقبول

## السياق
يمكن للوكيل أن يكتب مشاهد HTML/CSS/JS خامّة (نمط `try/`)، أو أن يُخرج بيانات منظّمة يفسّرها محرّك ثابت.

## القرار
الوكيل يُخرج **JSON** مطابقًا لعقد المشهد (zod في `packages/core`)، ومحرّك `packages/render-engine` يرسمه حتميًا.

## الأسباب
- أمان وموثوقية: يمكن التحقق والرفض وإعادة التوليد.
- اتّساق بصري عبر المشاهد والمشاريع.
- ربط مباشر مع طبقات المحرر (كل طبقة = عنصر JSON).
- حتمية التسجيل (`__seek(t)`).

## الأثر
حاجة لمحرّك عرض غنيّ بأنواع طبقات محدّدة، وتوسيع العقد تدريجيًّا.
