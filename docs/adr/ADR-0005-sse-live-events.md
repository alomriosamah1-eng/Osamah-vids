# ADR-0005 — اللحظية عبر SSE لا polling

- **التاريخ**: 2026-10-10
- **الحالة**: مقبول

## السياق
المشروع القديم يعتمد polling كل 1500ms، لا يكفي لمتطلّب «كل شيء لحظي» في المحرر.

## القرار
بثّ أحداث الخادم عبر **SSE** (`GET /api/projects/:id/events`)؛ الواجهة تشترك بـ `EventSource`.

## الأسباب
- أبسط من WebSocket، أحادي الاتجاه يكفينا.
- يعمل داخل Electron دون إعداد خاص.
- يعيد الاتصال تلقائيًا.

## الأثر
واجهة موحّدة للأحداث (`Envelope`) يستهلكها مخزن المحرر.
